# Changelog

## 1.0.0 — 2026-10-05

First public release.

- Full EOS™ implementation program: onboarding (Organizational Checkup™,
  workspace scan, tempo recommendation), 3 phases / 7 tools, substance
  rubrics and phase gates, graduation.
- Operating cadences: weekly L10™, quarterly planning, State-of-the-Company,
  annual planning.
- Calendar anchors captured at onboarding (fiscal year, L10 slot, quarterly
  and annual windows) drive time-based routing.
- Capacity-protection pauses are honored on resume; paused weeks don't
  count as drift.
- Mid-year Organizational Checkup with its own flow (week 13 / 26 / 39 by
  tempo).
- Converses in the user's language; document language chosen at onboarding.
- Packaged as a Claude Code plugin marketplace and as an uploadable skill
  ZIP for Cowork / claude.ai.
