# People Analyzer™

> **Status:** empty_template — to be filled in with the leadership team
> **Team-required:** yes (see `rocksolid/rules/team-required-tools.md`)
> **Source:** Wickman, *Traction*, Chapter 4 — The People Component

## How to use this file

Score every leadership team member against the company's Core Values
and against GWC™ (Get it / Want it / Capacity) in the same grid. This
is the tool that makes "right person, right seat" visible at a glance.
Run it as a team calibration, not a solo opinion — the scores only
bind when the team agrees on them.

## The two scoring systems on this grid (do not conflate)

This grid uses **two different scales** on the same row. Keep them
separate:

| Columns               | Scale        | Allowed values      |
|-----------------------|--------------|---------------------|
| Core Values (left)    | Three-value  | `+`, `+/-`, `-`     |
| G / W / C (right)     | Binary       | `Y`, `N`            |

- **Core Values (three-value):** `+` = lives the value most of the time,
  `+/-` = lives it sometimes, `-` = rarely lives it.
- **GWC (binary):** `Y` or `N` only. No `+/-` is permitted in a GWC
  column — "mostly" on Get it, Want it, or Capacity is treated as `N`.

Any row that mixes the scales (for example, a `+/-` in a GWC column) is
invalid and must be corrected before the tool is considered complete.

## Rules (from the substance rubric)

- **All Core Values from the V/TO™ appear as columns.** Drift from the
  canonical V/TO Core Values is not allowed — reconcile if they differ.
- **Every leadership team member is a row.** No one on the leadership
  team is exempt from being scored.
- **Every cell is filled.** Blank cells are not "unsure" — they are
  failures of the exercise.
- **The bar is met for every leadership team member.** The default bar
  for five Core Values is `3 +, 2 +/-, 0 -` and `Y / Y / Y` on GWC.
  Each team sets its own bar — but once set, it applies to everyone.
- **People Analyzer Core Values match the V/TO Core Values** once the
  V/TO exists.

## Below-the-bar actions

For every row where "Meets bar?" is no, record the plan. The options
are: move to a better-fit seat, enter the Three-Strike Rule process,
or transition the person out. Ignoring a below-the-bar result is the
one outcome that teaches the rest of the company that Core Values are
negotiable.
