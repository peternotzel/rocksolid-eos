# The People Analyzer

The People Analyzer™ is the simplest tool in the People component of the
Entrepreneurial Operating System™ (EOS™), and one of the most powerful
because it forces a leadership team to make every people decision against
the same explicit criteria. The tool is a single grid: people in rows,
evaluation criteria in columns. Half of the columns evaluate "right person"
fit (alignment with the company's Core Values). The other half evaluate
"right seat" fit using the GWC™ filter — Get it, Want it, Capacity to do
it. Both halves live on the same page so the team can see at a glance
whether a person clears the bar on both axes simultaneously.

The tool's value is not analytical sophistication — there is none. Its
value is that it makes subjective people decisions visible and comparable.
Once the grid is filled in, arguments stop being about feelings and start
being about specific scores against specific criteria.

## Two scoring systems on one grid

The most important and most easily missed feature of the People Analyzer is
that it uses **two different scoring systems** on the same grid. They are
not interchangeable, and conflating them collapses the tool.

### Left side — Core Values columns (three-symbol scoring)

One column per core value. For a company with five core values, there are
five Core Values columns. Each cell holds one of three marks:

- `+` — the person lives this value most of the time
- `+/-` — the person lives this value some of the time and not other times
- `-` — the person rarely lives this value

The three-symbol system is intentionally fuzzy. Core Values are cultural
behaviors observed over months, not binary attributes that can be flipped
on or off. The `+/-` mark exists specifically to capture the "depends on the
day" reality of real people without forcing a false yes or no.

### Right side — GWC columns (two-symbol scoring)

Three columns labeled G, W, and C. Each cell holds one of two marks:

- `Y` — yes, this person does Get it / Want it / has Capacity for it
- `N` — no

There is **no `+/-` allowed in the GWC columns**. GWC is deliberately
binary: "mostly" is treated as a no. The reason is that ambiguity on seat
fit is exactly the disease the tool exists to cure. Two-out-of-three is not
a partial pass — it is a fail.

### Why the distinction matters

A pure text reader of the EOS literature can easily assume that all columns
on the People Analyzer use the same scoring scheme. The visual diagram in
the book makes the distinction unambiguous: the left half of the grid uses
`+ / +/- / -` and the right half uses `Y / N`. Any digital implementation of
the tool must enforce this distinction at the form level — Core Values
cells should constrain to the three-symbol scale and GWC cells should
constrain to yes/no, with no overlap.

## "The bar" — the team's minimum acceptable score

Every leadership team using the People Analyzer sets a **bar** — the
minimum score they will accept for anyone in the company. The bar is the
specific combination of marks that defines the line between "above the bar"
(stays, gets developed) and "below the bar" (gets the Three-Strike Rule and
ultimately exits if no improvement).

Wickman's recommended bar for a company with five core values is:

- 3 `+` marks
- 2 `+/-` marks
- 0 `-` marks
- `Y` on all three of G, W, and C

That recommendation is not a universal law. It is a starting point. Some
teams set a higher bar — for example, 4 `+` and 1 `+/-`. A few set a
slightly lower bar in the early days while they are still calibrating. The
mechanical value of the bar is that once it is set, every manager knows
exactly what acceptable looks like, and there is no room for subjective
argument about whether a given person is a fit. "Below the bar" becomes a
factual claim, not an opinion.

The bar is set once by the leadership team, written down, and applied
consistently across the entire company.

## How the grid is used

The People Analyzer is not a one-time exercise. It runs on a continuous
cadence:

- **Quarterly reviews:** every direct report of every leader is scored on
  the grid as part of the quarterly cycle
- **Hiring decisions:** before a new hire starts, the leader scores the
  candidate on a People Analyzer grid using their interview observations,
  and the bar applies
- **Termination decisions:** before any termination conversation, the
  person's current grid scores are reviewed against the bar
- **Promotion decisions:** when moving someone into a new seat, score them
  against the new seat using GWC; the Core Values column scores carry over

The grid lives in the company's people-management system (or a simple
shared document) and is updated as observations accumulate. It is not a
"once a year" performance review artifact.

## Connection to the rest of the People component

The People Analyzer is the operational tool that makes the "Right Person,
Right Seat" framework concrete. The Core Values columns evaluate the
"right person" half. The GWC columns evaluate the "right seat" half.
Together, the grid produces a single page that tells the leadership team
which of the four quadrants any individual currently sits in — and what
needs to happen next.

When a person scores below the bar, the next move is not immediate
termination. It is the Three-Strike Rule — a structured three-round
conversation over roughly ninety days that gives the person specific
feedback on the gap, clear expectations, and time to change. Most people
either rise above the bar within the first or second strike, or they
self-select out before the third strike because the process makes the
mismatch obvious to them too.

## Criteria / Rules

- Every row is one person being evaluated.
- Every Core Values column is one of the company's actual Core Values
  (typically 3 to 7 columns).
- Core Values cells are constrained to `+`, `+/-`, or `-`. No other marks.
- GWC columns are exactly three: G, W, C. Always three, in that order.
- GWC cells are constrained to `Y` or `N`. No `+/-` allowed.
- The team has explicitly set a bar before scoring anyone.
- The bar is documented and applied consistently across the whole company,
  not adjusted person-by-person.
- Every person on the leadership team meets or exceeds the bar.

## Common pitfalls

- Allowing `+/-` in GWC columns to soften a hard "no" — destroys the binary
  discipline that makes seat fit decidable.
- Conflating the two scoring systems — using `Y/N` for Core Values or
  `+/-` for GWC.
- Setting the bar implicitly ("we'll know it when we see it") instead of
  explicitly — every people decision becomes an argument again.
- Scoring someone above the bar because they are a long-tenured friend,
  even though the marks tell a different story.
- Using the grid only at annual review time — the tool is meant to live
  in the quarterly cadence and inform every hire/fire/promote decision.
- Skipping the People Analyzer for the leadership team itself because it
  feels awkward — the leaders are exactly the people who need to model
  the standard.

## When to apply

- Phase 1: build the grid as soon as Core Values are drafted, even before
  the V/TO™ formally finalizes them
- Every quarterly review cycle: re-score every direct report
- Every hiring decision: score the candidate before extending an offer
- Every termination decision: confirm the person is below the bar against
  documented criteria
- Whenever the leadership team is having a "we don't know what to do about
  this person" conversation — the grid usually answers it
