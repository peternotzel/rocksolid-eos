# Examples

Real, unedited RockSolid sessions, run headless with `claude -p` on
2026-10-05 against a fictional company, **Brightline Freight** (freight
brokerage, 34 employees, 5-person leadership team, Hamburg).

| File | What it shows |
|---|---|
| [01-onboarding.md](01-onboarding.md) | `start eos` → checkup → scan → discrepancies → tempo → written plan |
| [02-bypass-challenge.md](02-bypass-challenge.md) | The team tries to skip the Accountability Chart |
| [03-scribe-mode-accountability-chart.md](03-scribe-mode-accountability-chart.md) | Whiteboard notes → structured chart, decisions, file written |
| [04-substance-check.md](04-substance-check.md) | `check my accountability chart` → 6/10, step stays in progress |
| [05-l10-prep.md](05-l10-prep.md) | Week 11 Monday L10 prep |

## Workspaces

- [`brightline-week1/`](brightline-week1/) is exactly what the folder looked
  like after sessions 01–04. `README.md` and `docs/` were the inputs;
  `eos-*.md` and `eos-deliverables/` were written by RockSolid.
- [`brightline-week11/`](brightline-week11/) is a fast-forward for the L10
  demo. The state, Rocks, Scorecard, Issues List and the L10 notes up to
  2026-09-28 were **seeded as fixtures** (that's why RockSolid flags some
  inconsistencies in them). `eos-deliverables/l10-notes/2026-10-05.md`
  was written by RockSolid in session 05.

User turns were scripted to move the demo along; assistant turns are
verbatim.
